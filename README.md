# CE4703 Assignment 1 – Modular C Program

A menu-driven C console program split into modules:

- `utilitycode.c/.h` – helper utilities (random numbers, input)
- `Arraycode.c/.h` – array operations
- `Mathcode.c/.h` – maths functions
- `menu.c/.h` – the interactive menu
- `main.c` – entry point

Doxygen documentation is in `DoxyGen/` (open `DoxyGen/html/index.html`).

## Build
Open `Assiment-Roshen.sln` in Visual Studio and run, or compile with any C compiler.
