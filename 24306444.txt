WF1 – randomInrange()

int min: the lower bound of the range

A random integer value between min and max.

Special Notes:

Uses the standard rand() function from <stdlib.h>.

Requires srand(time(NULL)) to initialize randomness before use.

WF2 – fillarrayfromkeyboard()

Parameters:

WF6 – randomizarray()

Description:
Rearranges (shuffles) all used elements in an array into a random order.
All unused (-1) elements remain at the end of the array.

Parameters:

int arr[]: the array whose elements are to be randomized

int size: total number of elements in the array

Returns:

Nothing (void function).

Special Notes:

Uses the Fisher–Yates shuffle method (simple random swapping).

Each used element changes position randomly, but values are not changed.

Pseudocode Representations
WF1 – randomInrange()

First Iteration:

Generate a random integer within a specified range.

Return the random number.

Second Iteration:

Use rand() to get a random integer value.

Compute range = max − min + 1.

Calculate number = (rand() % range) + min.

Return number.

WF2 – fillarrayfromkeyboard()

First Iteration:

Read numbers from keyboard and store them in the array.

Stop when a negative number is entered.

Mark all remaining elements as −1.

Return the number of used elements.

Second Iteration:

Set count = 0.

Repeat while count < capacity:
 a. Ask user to enter a value.
 b. If value < 0 → exit loop.
 c. Else store value in arr[count].
 d. Increment count.

For each remaining element from count to size−1, set arr[i] = −1.

Return count.

WF3 – fillarraywithRandno()

First Iteration:

Fill the array with random integers within a specified range.

Mark unused elements as −1.

Return the number of used elements.

Second Iteration:

Set count = 0.

Repeat while count < size:
 a. Generate random number = randomInrange(min, max).
 b. Store in arr[count].
 c. Increment count.

Set remaining elements to −1.

Return count.

WF4 – cleararray()

First Iteration:

Mark all elements as unused.

Second Iteration:

For each element in array from 0 to size−1:
 a. Set arr[i] = −1.

End loop.

WF5 – arraysort()

First Iteration:

Sort the used elements in ascending order.

Keep unused elements (−1) at the end of the array.

Second Iteration:

Determine usedCount = number of elements ≠ −1.

For i = 0 to usedCount − 1:
 a. For j = 0 to usedCount − i − 2:
  i. If arr[j] > arr[j+1], swap them.
 b. End inner loop.

End outer loop.

Leave remaining unused elements (−1) at the end.

WF6 – randomizarray()

First Iteration:

Randomly rearrange all used elements in the array.

Keep all unused (−1) elements at the end.

Second Iteration:

Count how many elements are used (≠ −1).

For i = usedCount − 1 down to 1:
 a. Generate random j = rand() % (i + 1).
 b. Swap arr[i] and arr[j].

End loop.

Leave unused (−1) elements unchanged at the end.

WF7 – printused()

First Iteration:

Display all used (≠ −1) elements of the array in braces { }.

Second Iteration:

Print “{”.

For each element in the array:
 a. If arr[i] != −1, print arr[i].
 b. If it’s not the last used element, print “, ”.

Print “}”.

If no used elements exist, print “{}”.

WF8 – printall()

First Iteration:

Display all elements of the array, including unused (−1) markers.

Second Iteration:

Print “{”.

For i = 0 to size − 1:
 a. Print arr[i].
 b. If not last element, print “, ”.

Print “}”.

WF9 – arrayminimum()

First Iteration:

Find the smallest used value in the array.

Second Iteration:

Set min = first used element.

For each element in array:
 a. If arr[i] != −1 and arr[i] < min, then min = arr[i].

Return min.

If all elements are −1, return 0 (or handle error).

WF10 – arraymaximum()

First Iteration:

Find the largest used value in the array.

Second Iteration:

Set max = first used element.

For each element in array:
 a. If arr[i] != −1 and arr[i] > max, then max = arr[i].

Return max.

Ignore all −1 values.
WF11 – arraysaverage()

First Iteration:

Calculate and return the average value of all used (≠ −1) elements in the array.

Second Iteration:

Set sum = 0, count = 0.

For each element in array:
 a. If arr[i] != −1:
  i. Add arr[i] to sum.
  ii. Increment count.

If count > 0, return sum / count.

Else, return 0.0.

WF12 – arraymedian()

First Iteration:

Return the median value of all used (≠ −1) elements in the array.

Second Iteration:

Copy all used elements into a temporary array.

Sort this temporary array in ascending order.

Determine the number of used elements n.

If n is odd, median = element at position n/2.

If n is even, median = average of elements at positions (n/2) - 1 and n/2.

Return the median value as a double.

WF13 – variancearray()

First Iteration:

Compute the variance of all used (≠ −1) elements in the array.

Second Iteration:

Calculate the average (mean) of all used elements.

Initialize sumSqDiff = 0, count = 0.

For each element:
 a. If arr[i] != −1:
  i. Add (arr[i] − avg)² to sumSqDiff.
  ii. Increment count.

Compute variance = sumSqDiff / count.

Return variance as a double.

WF14 – stddevarray()

First Iteration:

Compute and return the standard deviation of the used elements.

Second Iteration:

Calculate the variance using variancearray().

Compute stddev = sqrt(variance).

Return stddev as a double.

WF15 – arrayusedcount()

First Iteration:

Count and return how many used elements exist in the array.

Second Iteration:

Set count = 0.

For each element in array:
 a. If arr[i] != −1, increment count.

Return count.
