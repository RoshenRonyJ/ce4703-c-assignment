Detailed Description

Declares the menu system and high-level menu functions (MF1‚ÄìMF3).

This header file provides the interface to the application‚Äôs user-interaction layer. The functions declared here are implemented in menu.c and control the overall flow of the program. These functions call Working Functions (WF1‚ÄìWF15) to perform operations such as filling, clearing, sorting, and analysing arrays.

Functions included:

  • displayMenu() : Prints available menu options.
  • processMenu() : Executes behaviour based on user selection.
  • showMenu() : Main menu loop (runs until exit).
  • MF1() : Demonstrates basic array operations.
  • MF2() : Demonstrates sorting and randomization.
  • MF3() : Demonstrates full statistical analysis from user input.
