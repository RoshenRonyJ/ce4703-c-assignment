Detailed Description

Declares all Working Functions (WF1–WF15) used for array operations.

This module contains all low-level array manipulation functions required by the assignment. The functions perform input, random filling, sorting, printing, clearing, randomizing, used-element counting, and full statistical analysis.

Macros included:

  • UNUSED : Marks an unused array index (set to -1)
  • SWAP(a,b) : Safely swaps two integers

Working Functions implemented:

  • WF2 fillarrayfromkeyboard()
  • WF3 fillarraywithRandno()
  • WF4 cleararray()
  • WF5 arraysort()
  • WF6 randomizearray()
