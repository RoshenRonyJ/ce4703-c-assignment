Detailed Description

Implements all Working Functions (WF2–WF15) for array manipulation.

This module contains every low-level operation required for the assignment: keyboard input, random filling, clearing, sorting, printing, randomizing, statistics, and counting used elements.

Unused array positions are represented by the UNUSED macro (-1), and many functions operate only on used elements (i.e., values not equal to UNUSED).
