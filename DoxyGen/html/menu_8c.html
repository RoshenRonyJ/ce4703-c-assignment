Detailed Description

Fills an array with values entered by the user.

Implements the main menu system and high-level program functions (MF1–MF3).

Parameters
arrThe array to fill.
sizeThe maximum size of the array.
Returns
The number of used elements.

Reads integers from the keyboard until a negative value is entered. All valid numbers are stored sequentially. Remaining elements are set to UNUSED.

This module provides the user interface for the application. It displays menu options, reads user input, and calls the relevant functions to perform specific operations on integer arrays (such as filling, sorting, clearing, and calculating statistics).

Functions in this file:

  • displayMenu(): Prints the available user options.
  • processMenu(): Handles the user's numeric choice.
  • showMenu(): Keeps the application running until exit.
  • MF1(): Demonstrates basic array manipulation and min/max operations.
  • MF2(): Demonstrates sorting and randomizing arrays.
  • MF3(): Demonstrates statistical calculations from user input.

void displayMenu ( void )

Displays the main menu with available options.

Prints a numbered list of available functions (MF1–MF3) and an option to exit the application. The user must enter a number (1–4) to continue.

Note
This function does not take any input or return a value. Prints the menu options for the user. This function only prints text—no input is handled here.

◆ MF1()

void MF1 ( void )

Demonstrates basic array operations.

Performs the operations defined for MF1. Typically: filling arrays, clearing, sorting, and finding min/max.

MF1 performs the following actions:

  1. Creates and prints arrays with used and unused elements.
  2. Clears one array completely.
  3. Displays another pre-defined array.
  4. Prints the minimum and maximum values of that array.

It helps demonstrate how “used” and “unused” markers (-1) are handled and how min/max functions operate.

Performs the operations defined for MF2. Typically: randomizing and sorting array values.

MF2 performs the following:

  1. Fills an array with random integers in a range.
  2. Displays the unsorted (random) array.
  3. Sorts the array in ascending order.
  4. Randomizes the sorted array again.

◆ MF3()

void MF3 ( void )

Demonstrates user input and statistical calculations.

Performs the operations defined for MF3. Typically: keyboard input and computing statistical values.

MF3 allows the user to input integer values into an array. It then computes and displays:

  • The number of used elements
  • Minimum and maximum values
  • Average and median values
  • Variance and standard deviation

This function demonstrates how to combine input, sorting, and mathematical computations in one workflow.

Note
Automatically ignores unused (-1) array entries.

◆ processMenu()

void processMenu ( int choice)

Executes a menu option based on user choice.

Handles the user's choice and performs the corresponding action.

Parameters
choiceThe integer value entered by the user.

Based on the number entered, this function triggers:

  • MF1(): Basic array manipulation.
  • MF2(): Randomization and sorting demonstration.
  • MF3(): Statistical computation from user input.
  • 4: Exits the program.

If the input is invalid (not 1–4), a warning message is displayed. Handles what to do when user enters a choice. Calls MF1, MF2, MF3 or exits depending on the number.

void showMenu ( void )

Runs the main menu loop that keeps the program active until exit.

Continuously displays the main menu, reads the user's choice, and processes it using processMenu(). The loop terminates only when the user selects option 4 (Exit Application).
