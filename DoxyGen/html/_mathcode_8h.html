Detailed Description

Declares mathematical helper functions for variance and standard deviation.

This module provides the mathematical functions required by the assignment that are not strictly “array operations” but are closely related to the statistical working functions (WF11–WF14).

Functions declared here:

  • variancearray(): Computes variance of used array elements.
  • standevarray(): Computes standard deviation of used elements.

These functions rely on the UNUSED macro to ignore unused positions.
