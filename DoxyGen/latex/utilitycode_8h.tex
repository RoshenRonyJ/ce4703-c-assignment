\doxysubsection{Detailed Description}
Declares general-\/purpose utility functions used across the program. 

This module provides helper functions that are not tied to specific working functions but are required throughout the project. The primary utility implemented here is the random number generator, which returns numbers in an inclusive range.

Functions in this module include\+:
\begin{DoxyItemize}
\item \doxylink{utilitycode_8h_a26927eafc4b6c937b626631935e6e9b7}{random\+Inrange()} \+: Returns a random integer within a specified range.
\end{DoxyItemize}

These functions are used by several Working Functions, such as WF3 (random fill) and WF6 (randomize/shuffle), as well as menu operations MF1–\+MF3.
