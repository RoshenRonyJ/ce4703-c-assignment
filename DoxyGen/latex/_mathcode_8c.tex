\doxysubsection{Detailed Description}
Implements the mathematical Working Functions (WF9–\+WF14). 

This module contains all statistical and mathematical operations used by the array system. These functions operate only on "{}used"{} array elements, where unused values are marked with the UNUSED macro (-\/1). The functions implemented include\+:


\begin{DoxyItemize}
\item arraymin() (WF9)
\item arraymax() (WF10)
\item \doxylink{_mathcode_8c_ae0b255b7cbc88f5beb955b05e6648328}{arraysaverage()} (WF11)
\item \doxylink{_mathcode_8c_aa03fad71d41635d3a58593cac426fbb2}{arraymedian()} (WF12)
\item \doxylink{_mathcode_8c_ad0cbfb878d0f3727db88a85151a04a46}{variancearray()} (WF13)
\item \doxylink{_mathcode_8c_aaa41e5a878830de2efb6d1d19e8d3408}{standevarray()} (WF14)
\end{DoxyItemize}

These functions are invoked primarily by MF3 in the menu system.
